# pairwise-avclock-drift

长片播放到第二小时，字幕比口型慢了近一秒，音频按声卡采样计数走，视频按系统时钟走，两边没有共同时基；音频时钟用回调次数估算，回调丢帧后时钟直接跳；视频丢帧时没有把显示时间往后顺延，下一帧提前显示，画面轻微快进；音频重采样器的比率固定 1.0，声卡实际 48.002kHz，一小时累计几十毫秒；seek 之后音频时钟从零开始，视频继续用绝对时间，两边差出一个片长；变速播放时视频时间戳按倍速缩放，音频时钟没跟着改，倍速下口型错位；蓝牙耳机延迟没有补偿，音频比画面晚 200ms 且随连接状态变化；暂停恢复时用一个暂停时长去补两边，但音频缓冲里还有未播完的数据；立体声切到 5.1 时音频管线重建，时钟短暂停走；片尾字幕与画面同时结束，视频先到 EOF 触发停止，最后一句音频被截断。media/avclock_drift.py 是核心，tests/test_avclock_drift.py 15个红。要修的是：统一时基；按采样计数；丢帧顺延；动态比率校正；seek 同步重置；倍速统一缩放；延迟补偿；按缓冲水位恢复；重建期冻结时钟；EOF 等音频播完。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
